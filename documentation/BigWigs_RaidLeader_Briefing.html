1. Incident Report & Root Cause Analysis

The Problem in Previous Raid (Why Pysanka & Healers Alerted Us):
During the September 4 raid, healers and raiders experienced complete silence during Nefarian class calls: zero audio alerts ("Beware"), zero on-screen warning signs, zero raid chat messages, and zero timer bars.

In commit 8ecaa3a, support for Turtle WoW 1.18.1 dual class calls was introduced using two sequential sync channels (classCallA and classCallB). However, the handler for classCallA was programmed only to record classA = rest and deferred all alerts until classCallB arrived.

2. Class-Specific Tactical Directives for the Raid

PRIESTS — Corrupted Healing (CRITICAL)

Direct heals apply a massive stacking Shadow DoT to the target instead of healing.

  • Authorized Spells: Renew and Power Word: Shield ONLY!
  • Forbidden Spells: Cancel any in-flight Flash Heal or Greater Heal immediately.
  • BigWigs Alert: Loud "Beware" horn + flashing Renew icon + "YOUR CLASS CALL".
WARRIORS — Berserker Stance Lock

All warriors forced into Berserker Stance, taking +20% increased damage.

  • Tank Action: Main Tank takes 20% more damage. Prepare defensive cooldowns (Shield Wall, Last Stand).
  • Healer Action: Pre-shield MT and maintain maximum HoT coverage.
  • BigWigs Alert: Automatic stance alert + Berserker icon warning.
DRUIDS — Cat Form Lock

Druids afflicted by Involuntary Transformation, locked in Cat Form for 30s.

  • Resto Druids cannot heal. Feral tanks lose Bear armor/health pool.
  • DPS cats must watch threat closely to avoid pulling Nefarian.
SHAMANS — Corrupted Totems

Shamans drop hostile Corrupted Stoneskin and Healing Stream Totems.

  • Hostile totems grant huge buffs/heals to Nefarian and Bone Constructs.
  • Action: Melee and hunters must tab-target and kill all Corrupted Totems.

4. Raid Leader Action Checklist (Pre-Raid Briefing)

Mandatory Pre-Raid Verification Steps:
  1. Enforce Raid Addon Updates:
    Ask all raiders to ensure they have updated to BigWigs Revision 30141 (Master commit 3e1a711).
    To audit the raid in-game, type:
    /bw version  or  /bw versionquery
    Raiders on older revisions (30140 or earlier 30141 commits) will show in red/yellow and should update immediately to share the new per-class comm channels.
  2. Priest Healer Profile Optimization:
    Priest healers should execute the built-in profile command for optimized bar positioning and emphasis:
    /bw priest
    This arranges Class Call, Corrupted Healing, and Mind Control bars directly in primary healer eye-line.
  3. In-Game Dry Run Test:
    The Raid Leader or any officer can test the full Nefarian encounter flow (all 3 phases, single class call, and dual class call transition) by running:
    /run BigWigs:GetModule("Nefarian"):Test()
    This executes a 40-second simulation displaying all timers, warning signs, audio cues, and bar transitions without engaging the actual boss.
  4. Passive Backup Assurance:
    Even if a raider has monster yell chat muted or is out of yell range, BigWigs 30141 now actively inspects combat log debuffs (Involuntary Transformation, Corrupted Healing, Berserk). The class call will trigger automatically on the first tick!
